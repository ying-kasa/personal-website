经常有人问「前端应该怎么学」，正好借这个网站整理一份我自己的路线。不一定适合所有人，但每一步都是真实走过的。

## 第一阶段：三件套基础

HTML、CSS、JavaScript 是绕不过去的的地基：

- **HTML**：语义化标签比「能显示就行」重要得多
- **CSS**：重点啃透盒模型、Flex 布局、Grid 布局，响应式设计
- **JavaScript**：变量类型、作用域、闭包、异步（Promise / async-await）、DOM 操作

> 这个阶段最容易犯的错是「教程看完 = 学会了」。一定要做小项目：计算器、待办清单、天气页，做一遍胜过看十遍。

## 第二阶段：工程化与框架

1. **Git 与命令行**：版本控制是协作和部署的基础
2. **Vite**：理解开发服务器、热更新、构建产物
3. **Vue 3**：响应式原理、组件通信、组合式 API（`ref` / `computed` / `watch`）
4. **TypeScript**：可以先用起来再深入，类型体操不是重点

```ts
// 组合式 API 的心智模型：数据是响应式的，视图是数据的映射
const count = ref(0)
const double = computed(() => count.value * 2)

function increment() {
  count.value++
}
```

## 第三阶段：做一个完整的东西

框架学完不落地很快就会忘。一个「完整的东西」至少包含：

- 路由与多页面
- 组件拆分与复用
- 数据请求与状态
- 部署上线（比如……这个网站就是一次练习）
