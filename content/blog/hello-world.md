想了很久要不要自己搭一个网站，最后还是动手了。这是本站的第一篇文章，用来记录「为什么做」和「怎么做」。

## 为什么要有自己的网站

社交平台的内容永远属于平台，而个人网站是真正属于自己的一个小角落：

- **内容归自己**：Markdown 文件存在自己的仓库里，想搬就搬
- **完全可定制**：从布局到配色，每一像素都可以改
- **最好的学习项目**：一个网站几乎覆盖前端的全部知识面

> 写下来，是最好的学习方式。这句话是这个网站存在的理由。

## 用了什么技术

整站没有服务器，是一套现代的静态方案：

| 部分 | 技术 |
| --- | --- |
| 框架 | Nuxt 4（Vue 3 + TypeScript） |
| 样式 | Tailwind CSS v4 |
| 内容 | Nuxt Content，Markdown 文件即文章 |
| 部署 | 推送代码自动构建上线 |

## 以后会写些什么

1. 前端学习笔记，把踩过的坑记下来
2. 偶尔的生活随笔和照片
